# Profile assets

- The typing greeting is a standalone SVG with a reduced-motion fallback.
- Technology icons are from [Skill Icons](https://github.com/tandpfun/skill-icons), revision `7f7e691e71aec64e8354bf697835e009d1ad80f8`. Their license is included in `icons/LICENSE.skill-icons`.
- The 3D contribution view is generated using [GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib).
- The contribution snake is generated using [snk](https://github.com/Platane/snk).

The daily profile workflow publishes 3D images to `profile-assets`. The snake workflow publishes independently to `output`.
